### Hi, I'm Terry (`@Terrygilligan`)

Full-stack web & PWA builder living in rural Bulgaria, building sovereign compliance platforms, offline-first browser utilities, and practical multi-tenant web apps—with a strong bias toward clarity, data residency, and software that earns its keep without dark patterns.

#### How I Build
- **Sovereignty & Boundaries First:** Regional data partitioning (`europe-west1`, `europe-west2`, `europe-west3`), fail-closed security, and zero-code-exfiltration workflows where appropriate.
- **Offline-First & Practical:** Browser-native utilities, local-first state where it makes sense, atomic localization across European languages, and automated WCAG 2.2 / CI quality gates.
- **Cost & Agent Discipline:** `$0`-idle-cost cloud habits, explicit architectural invariants, and tight agent governance so code stays readable, auditable, and maintainable.

#### Stack & Tooling
- **Languages & Frameworks:** TypeScript, React, Next.js, SvelteKit, Astro, Vite, Node.js / Fastify, Tailwind CSS
- **Infrastructure & Edge:** Google Cloud Platform, Firebase, Cloudflare Workers & Turnstile
- **Languages Spoken:** English (native), Dutch, German, and working Bulgarian

#### What I'm Working On
- **Compliance-Audit Engine** (`compliance-audit.eu` / `compliance-audit.info`) — EU/UK compliance verification, API security scanning, automated WCAG 2.2 / EN 301 549 checks, and tamper-evident audit trails.
- **Utility Hub & Games Hub** (`online-utilities.com`) — Offline-capable PWA suite of client-side tools and word/spelling games with multi-locale support.
- **VetCarePro** — Multi-tenant veterinary clinic management PWA with multi-language workflows and voice-assisted clinical note pipelines.
- **More Across the Workbench:** `mytoptwenty`, **MyDreamHouse Bulgaria**, **IceNet Bulgaria**, and **Zanat's Word Forge**.

#### Before the Code
Before full-stack web and PWA development, I spent decades across very different trades and roles in the UK and continental Europe—from master butchery and meat inspection to driving instruction, heavy logistics, and running small businesses. Away from the keyboard, I split time with my wife on our Bulgarian homestead—tending trees, bees, poultry, and solar/rainwater systems—and tinkering with old hardware. That mix of trades, travel, and hands-on problem-solving still shapes how I design software: straightforward, resilient, and built to last.
